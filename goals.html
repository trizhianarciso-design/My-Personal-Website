My Goals as a Student

Here are the aspirations I'm working toward. Tap a card to read more.

Short-Term Goals

Build a strong foundation in web development.

Over the next year, I want to get comfortable with HTML, CSS, and JavaScript by building small projects, like a personal portfolio and a few practice sites. I also plan to learn Git and GitHub so I can track my work and share it with others.

Long-Term Goals

Grow into a confident front-end developer.

My long-term goal is to build responsive, accessible, and well-designed websites for real users. I want to keep learning new tools and frameworks, and work on projects that make a real difference for the people who use them.

Personal Development

Become more organized, confident, and well-rounded.

I'm working on managing my time better, communicating clearly, and learning from my mistakes instead of avoiding them. I also want to build healthy habits, like staying consistent and asking for help when I need it, so I can handle challenges with confidence.

Career Goals

Start a career in tech and keep growing from there.

I'm aiming for an internship or entry-level role in web development where I can learn from experienced teammates and contribute to real projects. Over time, I'd like to take on more responsibility, mentor others, and eventually move into a leadership role.
