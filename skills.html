Skills I'm Developing

As a student, I'm learning by doing. I've picked up skills in coding, design, and communication by taking on projects I actually care about, and I've learned that the best way to get good at something is to ship it, get feedback, and make it better. I enjoy the moments where different interests collide, like using technical skills to solve a creative problem or explaining a complex idea simply. That habit of trying, adjusting, and trying again is what keeps me growing.

Information Technology

  • Building a foundation in HTML, CSS, and JavaScript
  • Learning the basics of responsive design for different screen sizes
  • Practicing accessible, user-friendly web page layouts
  • Developing problem-solving and debugging habits through small projects

Innovative Thinking

  • Planning a website's structure and layout with sketches and wireframes
  • Choosing colors, fonts, and imagery that fit a clear visual style
  • Designing with the user experience in mind, so pages are easy to navigate
  • Turning design ideas into working pages with HTML, CSS, and JavaScript
  • Testing and improving designs based on feedback

Communication

  • Explaining technical ideas in plain language to people with different backgrounds
  • Practicing clear written communication in emails, documentation, and project notes
  • Building active listening skills to understand what others actually need
  • Sharing ideas confidently through presentations and group discussions
  • Giving and receiving constructive feedback on team projects

Analytical Thinking

  • Breaking big problems into smaller steps to find a clear path forward
  • Using logical reasoning to spot patterns and trace errors in code
  • Practicing debugging by testing one change at a time and checking the results
  • Researching and comparing options before choosing a solution
  • Learning from mistakes by reviewing what went wrong and adjusting my approach
